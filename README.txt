FunHub — Complex Simulation Test Build v2

This is a TEST build for the separate funhub-stage-a GitHub Pages repository.

IMPORTANT:
- Upload ALL files in this package, not only the HTML files.
- The four large game pages depend on their JavaScript files:
  conquest.js, pirate.js, precision.js, survival.js
- style.css and script.js are also required by the wider FunHub site.
- Do NOT upload this package to the main funhub repository until testing is complete.

Complex games:
- conquest.html + conquest.js — World Conquest with a stylized world map, territories, armies, AI, economy, diplomacy and turn system.
- pirate.html + pirate.js — Pirate Empire with an explorable 2D sea, islands, crew, cargo, weather and events.
- precision.html + precision.js — Precision AI Range with moving virtual targets, waves, accuracy and combo scoring.
- survival.html + survival.js — Survival Outpost with creature waves, base integrity, energy, scanning, repairs and barrier pulses.

UI changes:
- Game pages are map-first.
- On phones the map uses almost the entire available screen.
- Back button is overlaid on the map.
- Game controls stay overlaid on the map instead of sitting below it.
- The map/canvas can resize while the controls remain fixed in place.

SEO canonical URLs point to the funhub-stage-a test site. Create a separate live-site package after testing.
